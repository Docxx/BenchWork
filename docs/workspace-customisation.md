# Workspace customisation

The Calendar card on Home offers Month, Week and Agenda. Its appearance button
changes day size, the first weekday, accent colour, daily-page markers and the
selected-day agenda. Choices are saved for this vault on this device. Use
Edit home to resize the card or move it. Day cells keep a controlled height
instead of expanding into oversized squares on a wide screen.

Reading desk starts with `Papers` when that folder exists. Otherwise choose a
papers folder in the vault. **Choose papers folder** lets you browse folders,
include or exclude subfolders and search the selected library. It does not scan
the entire vault unless you explicitly choose the vault root. Zotero citations
and evidence capture continue to work with PDFs opened elsewhere.

Knowledge graph adds folder and file-type filters and Constellation, Research
map and Minimal appearance presets. Disconnected groups start separately,
duplicate and self-connections are suppressed, and overlapping labels are
hidden while the active node remains labelled. Colours, glow, label visibility,
node size, spacing, connections, tags and unlinked files remain customisable.
Save the style to retain it. The graph displays existing file links and shared
tags; spatial proximity is not evidence of a research relationship.

Settings > Modules groups tools by purpose and adds search and enabled,
disabled and attention filters. Packs remain available, and dependency prompts
still apply when switching individual modules on or off. Disabling a module
never removes its files.
